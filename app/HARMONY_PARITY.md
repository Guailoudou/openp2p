# 安卓与鸿蒙体验对齐

基准：`ohos/entry/src/main/ets/`，本轮仅修改 `app/`。安卓前台服务、VPN 授权、电池设置及恢复策略保留平台实现。

已对照修改：

- 主页与日志／登录后的四页导航、滑动切页、悬浮核心按钮、页面标题与副标题。
- 页面宽度断点、浅色／深色配色、卡片、表单、弹层拖动及选择器。
- 核心连接状态、运行期间 Token 锁定、十进制非零 uint64 校验（含前导零）。
- 设备列表、双向侧滑、映射编辑默认值与远端设备保留、映射开关失败回滚。
- 网络成员 IP 复制、新成员草稿保留、网络保存校验与失败恢复。
- 账号资料脱敏与显示、注册协议、外观选项、关于页内容与链接。
- 切换主题／深色模式时保留网络草稿，已登录会话不因页面重建而重复登录；退出账号清除保留数据。
- 最近 500 行核心日志、自动滚动、错误行颜色与日志导出。

自动检查：在 `app/` 下运行（需要 JDK 17 和 Android SDK）：

```powershell
.\gradlew.bat :app:compileDebugKotlin :app:testDebugUnitTest :app:lintDebug
```

回归测试：`app/src/test/java/cn/parity/CoreTokenTest.kt` 覆盖零值、前导零、uint64 上限与溢出、非数字输入；`NetworkConfigTest.kt` 覆盖网络配置及成员草稿快照的独立性。

最新自动检查：编译、2 项单元测试、lint 通过。快照单元测试验证数据隔离，不替代主题切换的设备交互测试。

## 待设备验收

当前 `adb devices` 与 `devecocli device list --format json` 均无设备，也没有已配置的安卓模拟器。编译与静态检查不能证明两端实际渲染及联网体验完全一致，以下验收尚未执行：

- 小屏、横屏、平板、放大字体下的布局、键盘和安全区。
- 两端浅色／深色页面对照，以及六种主题色切换。
- 登录／注册／退出后的导航变化，弹层返回、侧滑与下拉刷新手势。
- 真实设备的映射增删改、远端检测、网络成员操作及失败提示。
- VPN 授权取消、启动／停止、云端配置下发与日志分享。

使用同一管理账号、相同设备列表及网络配置在两端验收；尚不能据自动检查宣称“体验完全一致”。
